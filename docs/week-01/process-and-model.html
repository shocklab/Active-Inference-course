The hypothesis-testing agent

Generative process and generative model

Distinguishing the process that produces observations from the model used to interpret them.

Week 1§220 min

An agent receives observations and uses them to infer something about its surroundings. We need to distinguish the process producing the observations from the model used to interpret them. The model may omit variables, use different categories, or describe the observation process incorrectly.

1The generative process

The generative process is what the world actually does. There are states of affairs out there, evolving according to whatever physics, chemistry and other agents dictate, and some of what they do impinges on the agent's sensory surface.

Write $\vartheta$ for the true state of the world and $o$ for what arrives at the sensory surface. The generative process specifies how $\vartheta$ evolves, and how $\vartheta$ gives rise to $o$. Write $a$ for the agent's actions, drawn from whatever set of things the agent can do: for a thermostat $a \in \{\text{heat}, \text{idle}\}$, for an animal a continuous space of muscle commands. Week 9 makes the discrete case concrete; the lamp example below has no actions at all, being about perception alone. If actions affect the environment, the process must specify that effect too. For example, moving a sensor changes the observations it receives. The lamp example below holds actions fixed so that we can examine perception alone.

The agent observes $o$, not $\vartheta$ directly. This does not mean $o$ carries no information about $\vartheta$: that information is what inference uses. It means the agent must infer the hidden state through its observations.

On the notation

Much of the free energy principle literature writes $\eta$, or sometimes $\vartheta$, for external states of the generative process, keeping the letter $s$ for states inside the agent's model. We follow that; $s$ is defined in the next section. When you meet a paper that writes $s$ for both, read carefully: the ambiguity is not always harmless.

This course uses $\vartheta$ for external process states. Later, $\eta$ denotes an inference rate; check the convention when moving between sources.

2The generative model

The generative model is the agent's account of where its observations come from. It is a joint probability distribution over observations and a set of quantities the agent treats as their causes:

$$P(o, s) \;=\; \underbrace{P(o \mid s)}_{\text{likelihood}} \; \underbrace{P(s)}_{\text{prior}} .$$
(1.2.1)

Here $s$ is a hidden state of the model. It labels a possible state of affairs in the model. It is not $\vartheta$, it need not correspond to anything in $\vartheta$, and there is no requirement that the two even have the same dimension or the same type.

The likelihood $P(o \mid s)$ says what observations the agent expects when the model-state is $s$. The likelihood is a conditional prediction within the model. When $s$ describes the lamp as on, it predicts what the sensor would report under that hypothesis. The prior $P(s)$ assigns probabilities before the new observation. Their product specifies the joint, from which marginal and conditional distributions follow.

The sensory states are the observations $o$, described here as part of the agent's interface. The active states $a$ describe how it influences the surroundings. Write $\mu$ for its internal states, such as physical variables encoding beliefs about $s$. Thus $s$ labels a hypothesis; $\mu$ is a physical state of a system representing beliefs about that hypothesis.

Definition 1.2.1Markov blanket

A set of variables is a Markov blanket separating internal from external states when conditioning on that set makes the two groups independent. For the proposed partition, the required statement is

$$P^*(\vartheta,\mu\mid o,a)=P^*(\vartheta\mid o,a)P^*(\mu\mid o,a).$$
(1.2.2)

The star marks the joint distribution of the physical process. This is an additional statistical condition to establish in a model. Drawing a sensory surface and action arrows does not establish it. The equality says that, once $o,a$ are known, learning $\mu$ adds no information about $\vartheta$ under this joint distribution.

For a simple example, suppose $\vartheta$ generates $o$, which generates $\mu$, and $a$ is fixed. The joint factorises as $P^*(\vartheta)P^*(o\mid\vartheta)P^*(\mu\mid o)$. Conditioning on $o$ and normalising the first two factors gives $P^*(\vartheta\mid o)P^*(\mu\mid o)$, which has the required independence. Adding feedback or other dependencies requires checking the condition again; a static factorisation does not settle a dynamical model.

Week 12 examines when such partitions are appropriate for organisms.

CarefulA model can be wrong and still be a model

Nothing above requires $P(o \mid s)$ to be the true likelihood, or $P(s)$ to be the true distribution over anything. The agent's model is a hypothesis. Much of what makes active inference interesting comes from watching what happens when the model and the process disagree in structured ways, which is also the route by which the framework has been applied to psychiatric conditions.

3Using and changing the model

The model evidence is $P(o)=\sum_sP(o\mid s)P(s)$. Lesson 3 derives its role in Bayes' theorem, and Lesson 5 examines algorithms for computing it. The sum runs over the model's hypotheses. Physically producing a sensor reading and calculating its probability are different operations.

An observation's surprise is $-\ln P(o)$ under the chosen model. Two agents can therefore assign different surprise to the same reading.

Inference holds the generative model fixed and changes beliefs about hidden states. Learning changes the model's parameters or structure. Action affects the process that generates later observations. Some models let action also change the observation channel, for example by turning a sensor. The consequences have to be specified rather than inferred from a slogan about perception and action.

A belief here is a probability distribution over possible states. It need not involve awareness. A Kalman filter's state estimate and covariance specify a Gaussian belief. A bimetallic thermostat need not explicitly represent any such distribution, even though we can model its feedback mathematically.

4Two agents and a lamp

Consider a lamp behind a frosted screen and two agents interpreting its sensor.

A lamp sits behind a frosted screen. The true state $\vartheta$ is on or off, each equally likely, and a light sensor reports bright or dim. The sensor is imperfect: when the lamp is on it reads bright with probability $0.8$, and when the lamp is off it still reads bright with probability $0.1$. That is the generative process, and it is a fact about the world, not about anybody's beliefs.

Now two agents watch the same screen.

Agent A has a model that matches: states $s \in \{\text{on}, \text{off}\}$, prior $P(s) = (0.5, 0.5)$, and a likelihood equal to the true one. Its evidence for a bright reading is

$$P(\text{bright}) = 0.5 \times 0.8 + 0.5 \times 0.1 = 0.45,$$
(1.2.3)

so a bright reading carries $-\ln 0.45 = 0.7985$ nats of surprise, in the natural-log units of Lesson 1, and by Bayes the posterior on the lamp being on is $0.5 \times 0.8 / 0.45 = 0.8889$.

Agent B has the same states and the same prior but believes its sensor is far better than it is: $0.99$ and $0.01$ in place of $0.8$ and $0.1$. Its evidence for bright is $0.50$, its surprise $0.6931$ nats, and its posterior $0.9900$.

We can now compare their predictions and beliefs.

Surprise belongs to the model. The two agents received the same reading from the same lamp and were surprised by different amounts, $0.7985$ against $0.6931$ nats. Nothing about the world distinguishes them. This is what it meant to say that $P(o)$ is computed from the model.

A wrong model is still a model. Agent B's likelihood is false, but nothing about it is ill-formed: its columns still sum to one, Bayes still applies, its posterior is still a distribution. The machinery does not detect the error. That is the answer to the checkpoint question below about a state called "predator" with no predator in the world.

Mismodelling has a price, and the price is exactly a divergence. Two pieces of notation first. Write $P^{*}$ with a star for a distribution belonging to the process, the frequencies the world actually produces, and $P_A$, $P_B$ with an agent's letter for the same distribution computed under that agent's model. The star is the world; the subscript is whose head it is in.

Over a long run the readings arrive with the true frequencies, bright $0.45$ of the time. Write $\bar{S}_X$ for the average surprise of an agent $X$: its per-observation surprise, weighted by how often each observation really turns up,

$$\bar{S}_X \;=\; \sum_{o} P^{*}(o)\,\big[-\ln P_X(o)\big].$$
(1.2.4)

For agent A this is $0.688139$ nats, which is exactly $\mathrm{H}[P^{*}(o)]$: the entropy of Lesson 1 applied to the world's own frequencies. The non-negativity calculation below shows why this is a lower bound on average surprise. Agent B averages $0.693147$ nats. The excess is $0.005008$ nats.

The Kullback–Leibler divergence of a finite distribution $p$ relative to $q$ is $D_{\mathrm{KL}}[p\|q]=\sum_o p(o)\ln[p(o)/q(o)]$. Terms with $p(o)=0$ contribute zero; if $p(o)>0$ but $q(o)=0$, the divergence is infinite. Here both model probabilities are positive.

$$D_{\mathrm{KL}}\big[P^{*}(o) \,\|\, P_B(o)\big] = 0.005008\ \text{nats},$$
(1.2.5)

Subtracting the actual entropy from the average surprise gives

$$\bar S_X-\mathrm H[P^*] =\sum_o P^*(o)[-\ln P_X(o)+\ln P^*(o)] =D_{\mathrm{KL}}[P^*\|P_X].$$

Why is this nonnegative? The elementary inequality $\ln z\le z-1$ for $z>0$ gives

$$-\sum_o p(o)\ln\frac{q(o)}{p(o)} \ge\sum_{o:p(o)>0}[p(o)-q(o)]\ge0.$$

The final inequality allows $q$ to put mass where $p$ is zero. Equality requires $p=q$. Thus a model matching the observation frequencies minimises average surprise, but matching those frequencies alone need not identify the correct hidden causes.

Exercise 1.2.1Verify the excess surprise

Verify (1.2.5) by hand: compute $P^{*}(\text{dim})$ and $P_B(\text{dim})$, then evaluate $\sum_o P^{*}(o)\ln\big[P^{*}(o)/P_B(o)\big]$.

Solution

The true marginals are $0.45$ and $0.55$. Agent B's are $0.50$ and $0.50$, since its assumed sensor is symmetric and its prior is flat. So

$$D_{\mathrm{KL}} = 0.45\ln\frac{ 0.45 }{ 0.50 } + 0.55\ln\frac{ 0.55 }{ 0.50 } = 0.005008.$$

The first term is negative and the second positive; the sum is positive, as any KL divergence must be. Note how small it is. Agent B is badly wrong about its sensor, yet pays only about five thousandths of a nat per reading, because the error happens to leave its marginal over observations nearly right. Being wrong about the world in a way that does not show up in your predictions is cheap, and Week 12 asks whether that should worry us.

Exercise 1.2.2Break the blanket

Take four binary variables $\vartheta, o, a, \mu$ and build a joint distribution in which $\vartheta$ influences $\mu$ only through $o$. Verify (1.2.2) numerically. Then add a direct dependence of $\mu$ on $\vartheta$ and show the equality fails.

Solution

Let $\vartheta$ be a fair coin and let the sensor copy it with probability $0.9$, flipping it otherwise. Let $\mu$ copy $o$ with probability $0.8$, flipping it otherwise, independently of $\vartheta$ conditional on $o$. Fix $a$ constant. Given $o=1$, the conditional probabilities are $P(\vartheta=1\mid o=1)=0.9$ and $P(\mu=1\mid o=1)=0.8$. The joint table is

$\vartheta$ $\mu$ $P(\vartheta,\mu\mid o=1)$
0 0 0.0200
0 1 0.0800
1 0 0.1800
1 1 0.7200

Each entry is the corresponding product of marginals. Complementing both binary labels gives the same verification for $o=0$.

Now change the generation of $\mu$: with probability $0.3$ copy $\vartheta$ directly; otherwise use the previous noisy copy of $o$. Given $o=1$,

$$P(\mu=1\mid\vartheta=1,o=1)=0.3+0.7(0.8)=0.8600,$$

whereas for $\vartheta=0$ it is $0.7(0.8)=0.5600$. Consequently the joint entry and the product of marginals differ:

$$P(\vartheta=1,\mu=1\mid o=1)=0.7740, \qquad P(\vartheta=1\mid o=1)P(\mu=1\mid o=1)=0.7470.$$

This explicit distribution fails conditional independence. A direct edge can permit such a failure; its presence alone would not prove failure for every possible parameter setting.

5Changing beliefs while holding evidence fixed

Take a binary lamp model with prior probability $P(s=\mathrm{on})=1/2$. Let $P(\mathrm{bright}\mid\mathrm{off})=0.20$ and write $\theta$ for $P(\mathrm{bright}\mid\mathrm{on})$, initially $0.80$. The parameter $\theta$ is a probability in $[0,1]$ describing sensor reliability. A bright reading arrives. Its evidence is $0.500$ and the exact posterior probability of on is $0.800$.

Represent an approximate belief by $Q(\mathrm{on})=q$ and $Q(\mathrm{off})=1-q$. Here $q\in[0,1]$ is a probability, not a state or a sensor parameter. Define

$$F(q)=\sum_s Q(s)\ln\frac{Q(s)}{P(s,\mathrm{bright})}.$$
(1.2.6)

This is the finite-state variational free energy. Terms with $Q(s)=0$ are interpreted by their limit. Substituting $P(s,\mathrm{bright})=P(s\mid\mathrm{bright})P(\mathrm{bright})$ gives

$$F(q)=D_{\mathrm{KL}}[Q\|P(s\mid\mathrm{bright})]-\ln P(\mathrm{bright}).$$
(1.2.7)

The logarithm splits a product into a sum, and the evidence term comes outside the expectation because $\sum_sQ(s)=1$. KL divergence is non-negative and is zero when the beliefs equal the exact posterior. Lesson 3 examines it in detail.

At $q=1/2$, free energy is $0.9163$ nats. Setting $q=0.800$ reduces it to $0.6931$ nats. The evidence has stayed at $0.500$ throughout: inference has reduced the gap, not the surprise of this observation under the model.

6Notation to carry forward

$\vartheta$True states of the world. The generative process. The agent never sees these.
$s$Hidden states in the agent's generative model. Latent variables the agent infers.
$o$Observations, the sensory states on the blanket. Shared by both sides.
$a$Actions, the active states on the blanket. Chosen by the agent, felt by the world.
$\mu$Internal states: the physical variables carrying the model. Not the same as $s$, which is a variable inside it. Returns in Week 5.
$P(o \mid s)$The likelihood. What the model says each state predicts.
$P(s)$The prior over states, before any observation.
$P(o)$The model evidence, or marginal likelihood. The quantity whose logarithm is minus the surprise.
$P(s \mid o)$The posterior. What the agent should believe after seeing $o$. The object of the next two lessons.
$P(o, s)$The joint distribution over observations and model states. The generative model itself, (1.2.1).
$P^{*}(\cdot)$A star marks a distribution belonging to the process: the frequencies the world actually produces. No agent can evaluate it.
$P_A(\cdot),\ P_B(\cdot)$A subscript marks the same distribution computed under a named agent's model.
$D_{\mathrm{KL}}[Q \,\|\, P]$Kullback–Leibler divergence, $\sum_x Q(x)\ln[Q(x)/P(x)]$. Non-negative, zero only when $Q = P$, and not symmetric. Lesson 3.
$\mathrm{H}[P]$Shannon entropy, $-\sum_x P(x)\ln P(x)$, in nats. Lesson 1.
